- Changing total supply, premine, treasury, reward, era length, or decay
- Re-introducing stake into consensus
- Changing GHOSTDAG k or target block time
- Changing the testnet network tag
- Deleting legacy constants “for cleanliness” without a plan
- Deploying #259 without an activation decision
- Force-pushing or self-merging
- Touching seed1 docker/volumes/nginx unless the prompt is an explicit ops task

1. Read `docs/AGENT-RULES.md` first.

5. After merge, update this plan or STATE.md in a follow-up docs PR.
